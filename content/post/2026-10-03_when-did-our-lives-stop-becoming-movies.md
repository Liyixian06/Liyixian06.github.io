和 GPT 老师畅聊了俩小时，感到现在国内的文娱作品即使是现代的题材，也看不出其中有什么观察现代生活的欲望，新的社会空间并没有能够成为类型故事的场景（举个例子，Only Murders in the Building 中犯罪播客已经可以成为古典谋杀喜剧的结构装置）。

如果一部片子讲年轻人租房却只能落到爱情和友情，讲互联网公司感兴趣的却只是霸总恋爱，那么所有这些租房中介、大厂裁员，都不过是一个已经存在几十年的故事的布景板，人物真正经历的生活仍然是高度类型化的：谈恋爱、升职、婆媳、出轨、买房、创业。吸收现代生活并不是去拍《逆行人生》（友邻对此片有言：“影片是借现实里观众最关注的东西来完成自己的戏，是戏巧借了现实，而不是现实凝结成戏，不仅与实际有隔，甚至有被利用的感觉”），而是让菜鸟驿站成为故事发生的地方。

回想《好东西》的舒适，大概不只是营造了性别友好的空间，也在于描绘了一种真实的都市生活——中产童话的批评在这里并不矛盾，作品的局部、目标人群的狭窄，都无碍于它所拥有的自然的现代性；关键并不在于播客、自媒体、乐队、婚后共同育儿这些元素本身，而是这些生活方式并没有停留在置景当中，而是与角色的行为逻辑相交织。一个人怎样认识陌生人，什么关系算是亲密关系，小孩会从哪里学到性别和成人世界的知识？城市生活和新的媒介已经改变了剧情能够发展的方式。

事实上，如果稍作思考，就能意识到中国有如此之多的类型空间——小区物业、家长群、闲鱼、平台劳动、快递收发点、儿童智能手表、宠物社会、产业园、城中村、政务服务中心、写字楼一层的外卖架——想想日本文化是怎么处理便利店、居酒屋、家庭餐厅、卡拉 OK 和电车的吧！

除了现代生活之外，还有另一个也许更大的问题是娱乐性。娱乐性不能简单等同于商业、类型化或者喜剧，很难一言以蔽之地概括；好莱坞存在这样一个巨大的中间地带，非常成熟的 entertainment，引用 GPT 的话，“一个有趣的 premise，几个讨喜的演员，一连串设计得不错的场面，适量的笑料、悬念、浪漫或者刺激，然后舒舒服服结束”。试举几例：《游戏之夜》《利刃出鞘》《十一罗汉》《猫鼠游戏》，以及你能想到的大量的 studio comedy、rom-com、thriller、adventure，娱乐观众就是足够正当的目标。我们需要更多的 caper，farce 和 whodunit——十二个互不相识的人报了同一个云南高端旅行小团，第三晚有人的东西丢了——并不是说国内没有这样的片子，只是离稳定的类型生产还十分遥远；你已经可以断断续续地看到《年会不能停！》《扬名立万》《八仙》，甚至《唐人街探案》，但一部成功了，它仍然被理解成一匹特殊的黑马，而不是证明现代中国生活本身可以源源不断地提供这样的娱乐。

也许在国内影视工业中凝结了最多生活细节，相对来讲也发展得最成熟的地方，是《小欢喜》这样的都市家庭剧，但似乎很少往前再走一步，将其高度加工成更多样的类型。其实令人扼腕的是，二三十年前确实曾经有过很好的光景，无论是冯小刚的贺岁喜剧、宁浩的黑色幽默，还是《人在囧途》系列，都是非常健康的商业娱乐的产物——写到这里，我去看了一眼《人在囧途》的豆瓣条目，发现热门短评区赫然一条 2010 年的评论：“中国电影市场缺的不是大片，缺的就是这种有诚意的中小成本的电影”——哎……

文化产品怎样能快速吸收新的生活？美国、英国和日本已经提供了很好的范例，就是那些低成本的文化生产媒介：脱口秀、late night、SNL、单口喜剧、播客、panel show、漫画、杂志连载、深夜综艺。这么一看，国内吸收现代生活最快的文娱形式，除了网文、短视频和小体量网剧（《破事精英》），可能还真是《一年一度喜剧大赛》和《脱口秀大会》，只是还没有形成能顺畅进入长篇类型影视的通道……salute to 马东。



**Appendix A. 还有什么没有进入故事？**

以下这些内容并不是没有出现在影视作品里，只是它们没有成为可以复用的故事机制：

- **群聊社会：** 家长群、业主群、工作群、校友群、病友群、兴趣群；潜水、截图、小群、撤回、踢人、群主；
- **平台服务：** 外卖骑手、网约车司机、代驾、闪送、跑腿、上门喂猫、家政平台、陪诊、宠物托运、上门维修、同城搬家；
- **二手社会：** 闲鱼、搬家出东西、分手卖前任礼物、倒爷、大学毕业季、租房家具、奇怪收藏、面交、到手刀、被骗、认识陌生人；
	- 每件二手物品都带着上一任主人的生活
- **现代小区：** 物业、门禁、快递柜、车位、业委会、租户和业主、遛狗、装修噪音、邻居群、保安、电梯监控、高空抛物、垃圾分类、公共区域堆东西，天然的 sitcom 场景；
- **新型儿童生活：** 儿童手表、托管班、兴趣班、研学、家长群、班级群、游戏皮肤、短视频、校园里流行的文具和玩具、家长替孩子维护社交关系；
	- 现在的小孩已经生活在一种过去完全不存在的半联网社会。
- **新型老年生活：** 微信群、短视频、直播购物、广场舞组织、老年大学、旅游团、社区食堂、相亲、保健品、智能手机求助、帮子女带孩子、候鸟式养老；
- **当代服务业：** 咖啡师、美甲师、健身教练、房产中介、宠物医生、婚礼策划、摄影师、剧本杀DM、密室NPC、医美咨询、留学中介、教培老师，每一个都有自己的行话、鄙视链、客人类型和职业伦理；
	- 看一个职业剧拍得好不好，一定要看它是否揭露了大量行业的工作细节。
- **消费机制：** 直播间、拼单、凑满减、会员体系、联名、黄牛、抢票、预售、种草、测评、退货、仅退款、代购、海淘；
	- *奇怪的是，中国可能拥有世界上最复杂的消费互联网生态，影视作品却很少真正利用它。*
- **互联网身份：** 小红书/豆瓣/微博/游戏/同人圈/工作微信里的不同人格，适合身份喜剧和悬疑；
- **弱关系：** 搭子、游戏好友、网友、同担、群友、前同事、遛狗认识的人；
- **租住生活：** 合租、转租、二房东、长租公寓、搬家、智能门锁、看房、中介、押金、室友突然搬走、前租客的快递不断寄来；
- **宠物社会：** 宠物医院、宠物群、猫舍犬舍、领养、寄养、上门喂猫、宠物友好商场、宠物殡葬、流浪猫狗的争议；
- **医疗之外的健康生活：** 体检、挂号、陪诊、牙科、医美、心理咨询、减肥、健身、睡眠监测、智能手环、中医养生和互联网健康信息；
- **AI：** 写报告、写作业、求职、恋爱咨询、家长辅导、教师查 AI、老板要求 AI 赋能。

**Appendix C. Plot Engines**

| Engine             | 核心问题                           | 基本循环                                                     | 例子 *（generated by GPT）*                                  | 典型作品       |
| ------------------ | ---------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | -------------- |
| Heist / Caper      | 能完成不可能的任务吗？             | goal → team → plan → complication → improvisation → reveal   | 六个人必须在演唱会开场前弄到六张连座票：有人研究平台规则，有人联系黄牛，有人负责实名信息；计划执行到一半，平台突然改变放票规则。 | 《十一罗汉》   |
| Mystery / Whodunit | 真相/凶手是谁？                    | clue → hypothesis → contradiction → suspect shift → reveal   | 小区业主大会前，所有人的物业费突然被匿名退回。十二个业主都有理由这么做，每发现一条新线索，最可疑的人就换一个。 | 《利刃出鞘》   |
| Farce              | 一个越滚越大的谎能圆多久？         | lie → cover-up → new lie → collision → explosion             | 爸爸把吐槽班主任的话误发进家长群，为了证明不是自己发的，只好编出第二个谎；最后老师、被嫁祸的家长和校长同时出现在家长会上。 | 《大人别出声》 |
| Road               | 能按时到达目的地吗？               | route → obstacle → detour → worse obstacle → deadline        | 两个互相看不顺眼的人必须除夕前赶回老家：飞机取消、火车没票、顺风车抛锚，只能不断换交通工具。 | 《人在囧途》   |
| Romance            | 两个人能在一起吗？                 | attraction → friction → intimacy → complication → separation → choice | 两个人因为每天在同一家咖啡店远程办公认识，从互相嫌弃到逐渐亲近；后来才发现其中一人正负责裁掉另一人的部门。 | 《电子情书》   |
| Buddy              | 两个不搭的人能合作吗？             | conflict → forced cooperation → bonding → rupture → reconciliation | 一个极度守规矩的物业经理和一个天天投诉物业的业主，不得不一起寻找小区里失踪的孩子。 | 《耐撕侦探》   |
| Con                | 谁骗过了谁？                       | deception → counter-deception → reversal → reveal            | 一个闲鱼骗子准备骗买家，结果发现买家也是骗子；双方都以为自己在设局，却不知道还有第三个人在骗他们两个。 | 《火柴人》     |
| Quest              | 能找到某样东西吗？                 | destination → obstacle → solution → larger obstacle          | 一个毕业生搬家前发现房东弄丢了自己的猫，于是必须在离开城市前一天沿着小区、宠物店、监控和邻居一路寻找。 | 《疯狂的石头》 |
| Escape / Survival  | 能活下来/出去吗？                  | threat → response → temporary safety → new threat            | 暴雨导致地下商场进水，一群陌生人必须在水位不断上涨的情况下寻找出口。 | 《活埋》       |
| Competition        | 谁会赢？                           | round → setback → adaptation → escalation → final round      | 四个小区为了街道广场舞比赛互相较劲，每轮比赛都逼着各队升级编舞、挖人、刺探对手。 | 《绝杀慕尼黑》 |
| Underdog           | 弱者能完成目标吗？                 | failure → training → progress → setback → final test         | 一群从来没踢过球的公司员工为了保住活动经费，被迫参加集团足球赛，从第一场惨败开始训练。 | 《洛奇》       |
| Chase              | 能追上/逃掉吗？                    | pursuit → escape → distance closes → reversal                | 一个跑腿员拿错了客户的包，发现三拨人都在追自己；他不断利用地铁、商场和居民楼摆脱他们，但每次刚甩掉一拨又碰上另一拨。 | 《西北偏北》   |
| Rescue             | 能及时救到人吗？                   | locate → approach → obstruction → clock                      | 一个孩子坐错高铁，父母只有两小时确定他在哪一站下车，并设法赶在列车继续开走前找到他。 | 《生死时速》   |
| Game / Puzzle      | 规则到底是什么？                   | discover rule → exploit → rule changes → mastery             | 几个人参加一个号称“全城实景游戏”的活动，逐渐发现每完成一个任务才会获得下一条规则，而有些玩家知道的规则和其他人不同。 | 《土拨鼠之日》 |
| Fish out of water  | 外来者能理解陌生世界的规则吗？     | rule discovery → violation → consequence → adaptation        | 一个从没上过网的老人为了替孙女经营网店，第一次接触直播、客服黑话、优惠券和平台算法，并不断误解其中规则。 | 《律政俏佳人》 |
| Containment        | 一个封闭空间里的秩序还能维持多久？ | pressure → fracture → resource loss → breakdown              | 暴雪让十二个人困在一家高速服务区，停电、食物减少、手机没信号之后，原本的小矛盾逐渐变成阵营冲突。 | 《十二怒汉》   |
| Escalating chaos   | 事情还能变得多糟？                 | problem → solution → larger problem → desperate solution → catastrophe | 男人发现今晚女友和父母会意外见面，于是请朋友假装房东阻止父母进门；朋友又被父母误认为女友，真正的房东此时敲门。 | 《游戏之夜》   |

> 注意，engine 不是 plot；比如，“一个人在闲鱼买到一台装着犯罪证据的手机”只是 premise，接下来完全可以装不同的 engine：
>
> - Mystery：手机原主人是谁？这些照片到底意味着什么？
> - Chase：有人发现手机落到他手里，于是开始追杀他。
> - Con：卖家、买家和第三方都试图骗走手机。
> - Caper：他组织几个人，要在对方发现之前用手机里的信息偷回某件东西。
> - Farce：他不敢让妻子知道为什么自己有这台手机，于是不断编谎，最后妻子、卖家、警察、真正的机主同时来到家里。
